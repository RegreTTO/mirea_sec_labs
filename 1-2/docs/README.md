# Лабораторные работы 1–2

Общий проект — безопасный файловый менеджер на Python с SQLite и конвейером GitHub Actions с локальной проверкой через act и публикацией образа в GHCR.

## Технические задания

1. [Лаба 1: файловый менеджер](lab-1.md) — файловые операции, JSON, XML, ZIP, пользователи, база данных и аудит.
2. [Лаба 2: CI/CD](lab-2.md) — контейнерная сборка, тестирование, SAST, локальный запуск через `act` и публикация Docker-образа в GHCR.

[Инструкция CI и GHCR](ci.md) описывает запуск и артефакты.

Для реализации используй эти ТЗ. Прямые указания пользователя о Python, SQLite и GitHub Actions заменяют альтернативы из методичек.
