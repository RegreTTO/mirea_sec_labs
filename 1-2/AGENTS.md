# Лабораторные работы по безопасной разработке

- Репозиторий: https://github.com/RegreTTO/mirea_sec_labs.
- По умолчанию отправляй коммиты прямо в основную ветку (`main`).
- Создавай PR только для второй лабораторной работы, чтобы проверить работу CI.
- Реализуй файловый менеджер на Python. Используй SQLite через стандартный модуль `sqlite3`, без отдельного сервера БД.
- Используй GitHub Actions. Локально запускай тот же workflow через `act` и Docker; не добавляй GitLab CI или GitLab Runner.
- Требования выбранной реализации находятся в `docs/lab-1.md` и `docs/lab-2.md`.
- `docs/` — адаптированные ТЗ и указатель учебных материалов.
- `docs/sources/` — снимки исходных методичек для сверки; примеры C# и GitLab не задают стек реализации.
- `docs/assets/` — локальные иллюстрации методичек, используемые через относительные ссылки.
- Сохраняй исходные материалы отдельно от адаптированных требований. Явно отмечай уточнения проекта и расхождения с методичками.
